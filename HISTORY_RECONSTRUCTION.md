# Reconstructed Development History

This Git history was reconstructed in August 2026 from preserved project source archives.
Each commit mirrors one preserved development snapshot, uses the archive timestamp, and includes
a Korean summary under `docs/history/`. The original Git object IDs were not available.

The rc15 source archive was not preserved. Its documented dev10z rebase is retained in the rc16
snapshot and `docs/RC15_DEV10Z_REBASE.md`; no fabricated rc15 source commit was created.

Generated build output, caches, logs, original Cult of the Lamb game data, and local secrets are
excluded. Annotated tags distinguish intermediate source snapshots from finalized RC packages.
