# ChzzkOfTheLamb

치지직(CHZZK) 방송의 시청자가 **Cult of the Lamb** 속 신도 모집과 게임 플레이에 참여할 수 있도록 연결해 주는 방송 연동 프로그램입니다.

스트리머가 게임에서 새 신도를 영입할 때 시청자가 채팅으로 추첨에 참여하고, 당첨자의 치지직 닉네임과 미리 선택한 외형을 신도에게 적용합니다. 치지직 후원은 마을 또는 던전 상황에 맞는 무작위 게임 효과로 변환되며, 진행 상황은 OBS 오버레이에 표시됩니다.

> 현재 배포 후보 버전: **v1.0.0-rc35**<br>
> 대상 환경: Windows 10/11, Steam판 Cult of the Lamb<br>
> 비공식 팬 프로젝트이며 Massive Monster, Devolver Digital, NAVER CHZZK와 제휴하거나 공식 지원을 받는 프로그램이 아닙니다.

## 만든 목적

ChzzkOfTheLamb은 단순히 채팅을 화면에 띄우는 도구가 아니라, 방송 시청자가 교단의 신도가 되고 게임 상황에 직접 영향을 주는 참여형 방송을 만들기 위해 개발되었습니다.

- 신도 모집을 채팅 참여형 추첨으로 전환
- 시청자가 자신의 신도 외형을 방송 전에 직접 선택
- 후원을 마을 관리와 던전 전투에 영향을 주는 이벤트로 연결
- 추첨, 당첨자, 후원 및 버프 상태를 OBS에 시각적으로 표시
- 스트리머가 복잡한 모드 설치나 클라우드 인증 정보를 직접 다루지 않도록 설치 과정 자동화

## 주요 기능

### 치지직 신도 추첨

- 게임에서 신도 영입 화면이 열리면 30초 추첨이 자동으로 시작됩니다.
- 시청자는 치지직 채팅에 `!신도`를 입력해 참여합니다.
- 한 추첨에는 한 번만 참여할 수 있습니다.
- 같은 저장 파일에 이미 신도로 등록된 시청자는 중복 등록되지 않습니다.
- 당첨자의 치지직 닉네임과 선택 외형이 게임이 생성한 신도에게 적용됩니다.
- 게임 속 이름표에는 초록색 `Chzzk` 표시가 붙어 일반 신도와 구분됩니다.

### 시청자 외형 설정 페이지

- 스트리머별 전용 웹주소를 제공합니다.
- 시청자는 치지직 계정으로 로그인한 뒤 형상, 색상, 종류를 미리 선택합니다.
- 현재 게임 저장 파일에서 해금되었고 스트리머가 허용한 외형만 선택할 수 있습니다.
- 저장한 외형은 이후 `!신도` 추첨에 당첨되었을 때 사용됩니다.
- 게임에서 새로운 일반 외형을 해금하면 선택 목록에 자동 반영됩니다.

### OBS 방송 오버레이

- 신도 추첨 시작, 남은 시간, 참가자 수 및 당첨 결과 표시
- 후원자, 후원 금액 및 발생한 이벤트 표시
- 던전의 공격력·이동속도 버프와 디버프, 남은 시간 표시
- 여러 후원이 연속으로 들어오면 순서대로 표시
- 추첨이 후원 카드를 가리더라도 남은 표시 시간을 보존해 추첨 종료 후 다시 표시
- 로딩, 일시정지, 대화 및 컷신 중에는 후원 적용과 제한시간을 함께 정지

### 자동 설치와 진단

설치 파일 하나로 다음 구성요소를 내려받아 SHA-256 검증 후 설치합니다.

- BepInEx 5.4.21 x64
- COTL_API 0.3.4
- COTL Korean Font Fix 4.2.1
- ChzzkOfTheLamb 게임 Mod
- ChzzkOfTheLamb Companion

사용자에게 AWS CLI, AWS SSO, .NET Runtime 또는 DLL 수동 복사를 요구하지 않습니다. 문제가 생기면 Companion의 `support` 명령으로 개인정보를 최대한 제거한 진단 ZIP을 만들 수 있으며, 파일은 자동 업로드되지 않습니다.

## 후원 시스템

치지직 후원 금액이 1,000원 이상이면 현재 게임 위치와 금액 구간에 맞는 이벤트 하나가 무작위로 선택됩니다. **도움 효과와 방해 효과가 모두 포함**되어 있으므로 방송에서 시청자에게 미리 안내하는 것을 권장합니다.

| 후원 금액 | 마을·일반 지역 | 던전 |
|---|---|---|
| 1,000~2,999원 | 신앙 소폭 증감, 신도 포만도 증가, 소규모 복합 효과 | 반 칸 회복·피해, 열정 20%, 이동속도 ±15%, 적 전체 피해 |
| 3,000~4,999원 | 신앙·포만도 중간 증감, 복합 축복 또는 방해 | 한 칸 회복·피해, 열정 35%, 이동·공격 ±20%, 적 전체 피해 |
| 5,000~9,999원 | 강한 신앙·포만도 증감, 풍요 또는 고난 | 한 칸 반 회복·피해, 열정 50%, 이동·공격 ±25%, 적 전체 큰 피해 |
| 10,000원 이상 | 전원 포식, 대신앙, 대축복 또는 대재난 | 두 칸 회복·피해, 열정 완전 충전, 이동·공격 ±40%, 적 전체 대폭발 |

- 던전 피해 이벤트는 후원으로 플레이어가 즉사하지 않도록 최소 반 칸의 체력을 남깁니다.
- 지속 효과는 같은 종류끼리 겹쳐 동시에 실행되지 않고 순서대로 대기합니다.
- 한 후원에서 이동속도와 공격력이 함께 바뀌는 경우 두 효과는 같은 시점에 시작됩니다.
- 로딩이나 장면 전환 중 들어온 후원은 대기열에 저장되며, 실제 적용 시점의 장소를 기준으로 마을/던전 규칙을 다시 결정합니다.
- 1,000원 미만 후원에는 게임 효과가 적용되지 않습니다.

> **현재 검증 상태:** 개발 후원으로 금액별 규칙, 게임 적용, 대기열, 장면 전환 및 OBS 표시는 검증했습니다. 실제 치지직 후원 수신은 채널 수익 창출 승인 후 추가 검증이 필요한 조건부 기능입니다.

## 빠른 시작

1. GitHub의 **Releases**에서 최신 `ChzzkOfTheLamb-Setup-...exe`를 내려받습니다.
2. Cult of the Lamb과 실행 중인 기존 Companion을 종료합니다.
3. 설치 파일을 실행하고 자동으로 찾은 게임 경로를 확인한 뒤 **설치**를 누릅니다.
4. 설치 완료 후 **Companion 실행**을 누릅니다.
5. 열린 브라우저에서 방송에 사용할 치지직 계정으로 로그인하고 접근을 승인합니다.
6. Companion은 방송을 사용하는 동안 종료하지 않습니다.
7. OBS에 Companion이 안내하는 로컬 오버레이 주소를 브라우저 소스로 추가합니다.
8. Companion의 `viewer copy` 명령으로 시청자 외형 설정 주소를 복사해 방송 공지나 채팅에 공유합니다.
9. Cult of the Lamb을 실행한 뒤 Companion에서 `status`를 입력해 `GAME=True`, `SYNC=READY`, `OVERLAY=ready`인지 확인합니다.

설치 화면, OBS 권장 설정, 시청자 안내문과 문제 해결 방법은 **[한글 사용자 설명서](docs/guides/USER_GUIDE_KO.md)**에서 자세히 확인할 수 있습니다.

## 스트리머가 방송 전에 확인할 것

- Companion이 `RELEASE / CHZZK LIVE` 모드로 실행되는지
- 로그인한 치지직 계정이 실제 방송 채널과 같은지
- Cult of the Lamb 저장 파일을 한 번 불러왔는지
- OBS 브라우저 소스가 보이지 않는 상태에서도 `status`의 `OVERLAY=ready`가 표시되는지
- 시청자 페이지에서 외형 목록이 보이고 저장되는지
- 시청자에게 `!신도` 참여 방식과 후원에 방해 효과도 포함된다는 사실을 안내했는지

## Companion 주요 명령

| 명령 | 설명 |
|---|---|
| `status` | 치지직, 게임, 저장 파일, 외형 목록, 후원 및 오버레이 연결 상태 확인 |
| `overlay` | OBS 브라우저 소스 주소 확인 |
| `viewer` | 시청자 외형 설정 페이지 주소 확인 |
| `viewer copy` | 시청자 페이지 주소를 클립보드에 복사 |
| `viewer open` | 시청자 페이지를 기본 브라우저로 열기 |
| `raffle start` | 추첨 수동 시작 |
| `raffle cancel` | 진행 중인 추첨 취소 |
| `raffle draw` | 추첨 즉시 마감 및 당첨자 선정 |
| `forms` | 시청자에게 공개된 외형 목록 확인 |
| `form allow <id>` | 외형 하나를 선택 가능 목록에 추가 |
| `form deny <id>` | 외형 하나를 선택 가능 목록에서 제외 |
| `refresh-forms` | 게임 외형 목록 다시 불러오기 |
| `support` | 바탕화면에 진단 ZIP 생성 |
| `support open` | 마지막 진단 ZIP을 파일 탐색기에서 선택 |
| `help` | 사용 가능한 명령 표시 |
| `exit` | Companion 정상 종료 |

## 구성 방식

```text
치지직 채팅·후원
        ↓
Companion ─────→ OBS 브라우저 오버레이
    ↕ 로컬 연결
게임 Mod ──────→ Cult of the Lamb
    ↕
시청자 외형 설정 웹페이지
```

- **Companion:** 치지직 로그인, 실시간 채팅·후원 수신, 추첨, OBS 서버 및 게임 전달을 담당합니다.
- **게임 Mod:** 신도 정보와 외형 적용, 마을·던전 후원 효과, 게임 상태 동기화를 담당합니다.
- **시청자 웹페이지:** 치지직 로그인과 개인 신도 외형 저장을 담당합니다.
- **OBS 오버레이:** `127.0.0.1`의 로컬 페이지로, 방송 PC 밖에 공개되지 않습니다.

## 로그와 사용자 데이터

| 구분 | 위치 |
|---|---|
| Companion 프로그램 | `%LOCALAPPDATA%\Programs\ChzzkOfTheLamb` |
| 사용자 설정·매핑 | `%LOCALAPPDATA%\ChzzkOfTheLamb` |
| Companion 로그 | `%LOCALAPPDATA%\ChzzkOfTheLamb\companion-rc35.log` |
| 설치 로그 | `%LOCALAPPDATA%\ChzzkOfTheLamb\installer.log` |
| 게임 Mod 로그 | `Cult of the Lamb\BepInEx\LogOutput.log` |

업데이트나 재설치 시 `%LOCALAPPDATA%\ChzzkOfTheLamb`의 사용자 데이터는 삭제하지 않습니다. OAuth 토큰, 설정 파일, 시청자 매핑·외형 데이터와 게임 세이브는 `support` ZIP에서 제외됩니다.

## 라이선스와 주의사항

현재 저장소에는 별도의 라이선스가 명시되어 있지 않으므로, 저작권자의 허가 없이 소스 코드를 복제·수정·재배포할 수 있는 것으로 간주해서는 안 됩니다. 게임 본체나 게임 데이터는 포함하지 않습니다. 게임 또는 치지직 API 업데이트로 호환성이 달라질 수 있으므로, 새 버전 설치 전에는 릴리스 설명과 알려진 문제를 확인하세요.
