# ChzzkOfTheLamb 한글 사용자 설명서

이 문서는 스트리머가 설치 파일을 내려받은 뒤 **설치 → 치지직 로그인 → OBS 설정 → 시청자 링크 공유 → 방송 전 점검**까지 순서대로 진행할 수 있도록 작성되었습니다.

## 1. 준비 사항

- Windows 10 또는 Windows 11 PC
- Steam판 Cult of the Lamb 설치
- 방송에 사용할 치지직 채널 계정
- OBS Studio
- 인터넷 연결

설치 전에 Cult of the Lamb과 기존 ChzzkOfTheLamb Companion을 모두 종료하세요. 게임을 실행한 상태에서 설치하면 일부 Mod 파일이 정상적으로 교체되지 않을 수 있습니다.

## 2. 릴리스 파일 내려받기

1. GitHub 저장소의 **Releases**를 엽니다.
2. 가장 최신 릴리스에서 `ChzzkOfTheLamb-Setup-버전.exe` 파일을 내려받습니다.
3. `source code.zip`이나 `source code.tar.gz`는 개발자용 소스이므로 일반 사용자는 받을 필요가 없습니다.

Windows SmartScreen이 게시자를 확인할 수 없다는 경고를 표시할 수 있습니다. 반드시 이 저장소의 공식 Releases에서 받은 파일인지 확인하고, 릴리스에 SHA-256 값이 제공된 경우 내려받은 파일과 대조한 뒤 실행하세요.

## 3. 프로그램 설치

1. 내려받은 Setup EXE를 실행합니다.
2. 설치기가 Steam 라이브러리에서 Cult of the Lamb 폴더를 자동으로 찾습니다.
3. 표시된 경로가 실제 게임 폴더인지 확인합니다.
4. 경로를 찾지 못했다면 **찾아보기**를 눌러 `Cult Of The Lamb.exe`가 있는 폴더를 선택합니다.
5. **설치**를 누르고 완료될 때까지 창을 닫지 않습니다.
6. 설치 완료 메시지가 나타나면 **Companion 실행**을 누릅니다.

설치기는 BepInEx, COTL_API, 한글 폰트 패치, 게임 Mod와 Companion을 자동으로 설치합니다. 구성요소마다 SHA-256을 확인하므로 다운로드가 손상되거나 배포 파일이 일치하지 않으면 설치를 중단합니다.

### 설치 위치

- 게임 Mod: Steam의 `Cult of the Lamb\BepInEx` 아래
- Companion: `%LOCALAPPDATA%\Programs\ChzzkOfTheLamb`
- 사용자 설정과 로그: `%LOCALAPPDATA%\ChzzkOfTheLamb`
- 바탕화면/시작 메뉴: Companion 바로가기

## 4. 치지직 로그인

1. Companion을 실행하면 검은색 콘솔 창이 열립니다.
2. 기본 브라우저에 치지직 로그인·승인 화면이 열립니다.
3. 방송에 사용할 치지직 계정인지 확인하고 접근을 승인합니다.
4. Companion 창에 `RELEASE / CHZZK LIVE`와 연결된 채널 이름이 표시되는지 확인합니다.
5. 이 창은 채팅, 후원, OBS와 게임을 연결하는 프로그램이므로 방송 중에는 종료하지 않습니다.

로그인 브라우저가 자동으로 열리지 않거나 인증이 끝나지 않는다면 Companion을 한 번 종료한 뒤 다시 실행하세요. VPN, 광고 차단 프로그램 또는 방화벽이 로컬 콜백 주소를 막고 있지 않은지도 확인합니다.

## 5. OBS 오버레이 설정

### 오버레이 주소 확인

Companion 창에 `overlay`를 입력하고 Enter를 누릅니다. 다음 형식의 로컬 주소가 표시됩니다.

```text
http://127.0.0.1:17883/overlay?v=...
```

표시된 전체 주소를 사용하세요. 버전이 붙은 주소는 업데이트 후 오래된 오버레이 화면이 남는 문제를 방지합니다.

### OBS에 추가

1. OBS의 **소스 목록**에서 `+`를 누릅니다.
2. **브라우저**를 선택합니다.
3. 새 소스 이름을 `ChzzkOfTheLamb 오버레이`로 지정합니다.
4. URL에 Companion이 표시한 오버레이 주소를 붙여넣습니다.
5. 너비와 높이를 현재 방송 캔버스와 동일하게 설정합니다.

| OBS 기준 해상도 | 너비 | 높이 |
|---|---:|---:|
| 1920×1080 방송 | 1920 | 1080 |
| 2560×1440 방송 | 2560 | 1440 |
| 1280×720 방송 | 1280 | 720 |

6. **사용자 지정 CSS**는 비워 둡니다.
7. 가능하면 **소스가 활성화되면 브라우저 새로고침**을 켭니다.
8. 평상시 아무것도 보이지 않는 것이 정상입니다. 오버레이 페이지의 배경은 투명합니다.
9. 소스에 변형이 적용되어 있다면 **변형 초기화**로 캔버스에 맞춥니다. 자르기나 별도 배율은 사용하지 않는 것이 좋습니다.

### 연결 확인

OBS 브라우저 소스를 켠 뒤 Companion에서 `status`를 입력합니다. `OVERLAY=ready`와 `OVERLAY_DOC_CURRENT=True`가 표시되면 정상입니다.

`OVERLAY=not-polling`이면 다음을 확인하세요.

- Companion이 계속 실행 중인지
- OBS URL이 `http://127.0.0.1:17883/overlay...`인지
- 브라우저 소스가 숨김 또는 비활성화 상태인지
- OBS 브라우저 소스의 **현재 페이지 새로고침**을 실행했는지
- 이전 버전 주소를 사용 중이라면 `overlay` 명령으로 새 주소를 다시 복사했는지

### 오버레이 표시 위치

- 추첨과 당첨 결과: 화면 중앙
- 후원 이벤트 카드: 화면 왼쪽 위에서 18px, 최대 너비 480px
- 지속 버프·디버프: 화면 왼쪽부터 오른쪽 방향으로 배치

후원 카드와 추첨 화면의 크기·위치는 서로 독립적입니다. OBS에서 브라우저 소스 자체를 잘라내면 카드가 보이지 않을 수 있으므로 전체 캔버스를 유지하세요.

## 6. 시청자 외형 설정 링크 공유

치지직 로그인이 끝나면 Companion에 `[VIEWER PAGE]` 배너와 스트리머 전용 주소가 표시됩니다. 주소에는 로그인한 스트리머의 채널 ID가 포함되므로 다른 방송의 링크와 바꾸어 사용하면 안 됩니다.

### 가장 간단한 복사 방법

Companion 창에서 `viewer copy`를 입력하면 주소가 Windows 클립보드에 복사됩니다. 직접 열어 확인하려면 `viewer open`, 주소를 다시 표시하려면 `viewer`를 입력합니다.

로그인 완료 후에는 바탕화면에 **CHZZK 시청자 외형 설정 페이지** 바로가기도 생성됩니다.

### 어디에 공유하면 좋은가

- 치지직 채널 공지
- 방송 설명 또는 고정 안내
- 방송 시작 전 채팅 공지
- 봇의 반복 안내 메시지
- 디스코드나 팬카페의 방송 안내 게시물

### 시청자에게 보낼 안내문

> 방송의 Cult of the Lamb 신도로 참여하고 싶다면 아래 링크에서 치지직으로 로그인한 뒤 원하는 신도 외형을 저장해 주세요. 게임에서 신도 모집이 시작되면 채팅에 `!신도`를 입력하면 추첨에 참여할 수 있습니다. 이미 같은 저장 파일에 신도로 등록된 계정은 다시 참여할 수 없습니다.<br>
> 외형 설정: `[Companion에서 복사한 시청자 페이지 주소]`

링크에 포함된 `?streamer=...` 부분을 지우지 마세요. 시청자는 자신의 치지직 계정으로 로그인해야 본인의 외형을 저장할 수 있습니다.

## 7. 게임 실행과 첫 동기화

1. Companion을 실행하고 치지직 로그인을 완료합니다.
2. Cult of the Lamb을 실행합니다.
3. 방송에 사용할 저장 파일을 불러와 실제 플레이 화면까지 들어갑니다.
4. Companion에서 `status`를 입력합니다.
5. 다음 항목을 확인합니다.

```text
GAME=True
GAME_SOCKET=True
GAME_READY=True
SYNC=READY
SAVE=slot_...
CATALOG=1 이상
OVERLAY=ready
```

외형 목록은 현재 저장 파일에서 해금된 신도 형상을 게임으로부터 읽어옵니다. 새 게임이거나 아직 외형을 불러오지 못한 경우 시청자 페이지에 “외형 목록이 아직 업로드되지 않았습니다”라고 나올 수 있습니다. 저장 파일을 불러온 상태로 잠시 기다리거나 Companion에서 `refresh-forms`를 입력하세요.

## 8. 신도 추첨 사용법

### 자동 추첨

게임에서 새 신도를 받아 이름과 외형을 정하는 영입 화면에 들어가면 추첨이 자동 시작됩니다.

1. OBS 중앙에 `!신도` 참여 안내와 30초 제한시간이 표시됩니다.
2. 시청자가 치지직 채팅에 `!신도`를 입력합니다.
3. 종료 시 한 명을 무작위로 뽑습니다.
4. 당첨자의 닉네임과 저장 외형을 새 신도에게 적용합니다.
5. 저장 외형이 없거나 현재 허용되지 않는 외형이면 게임에서 사용할 수 있는 안전한 기본값이 적용될 수 있습니다.

### 수동 명령

```text
raffle start   추첨 시작
raffle draw    즉시 마감하고 당첨자 선정
raffle cancel  추첨 취소
```

일반 방송에서는 게임의 신도 영입 화면과 연결된 자동 추첨 사용을 권장합니다. 게임에서 연결된 모집 대상이 없는 상태로 수동 추첨하면 당첨자를 뽑더라도 게임 데이터가 변경되지 않을 수 있습니다.

## 9. 후원 이벤트 안내

1,000원 이상의 치지직 후원이 들어오면 금액대와 현재 위치에 맞는 효과가 무작위로 결정됩니다.

### 마을 및 일반 지역

- 신앙 증가 또는 감소
- 일부 또는 전체 신도의 포만도 증가·감소
- 신앙과 포만도가 함께 변하는 축복·방해
- 고액 구간의 전원 포식, 대축복 또는 대재난

### 던전

- 체력 회복 또는 비치명 피해
- 열정 충전
- 이동속도 증가 또는 감소
- 공격력 증가 또는 감소
- 모든 적에게 피해
- 고액 구간의 강한 복합 버프·디버프

로딩, 장면 전환, 일시정지, 대화 또는 컷신 중 후원이 도착하면 즉시 적용하지 않고 대기합니다. 플레이 가능한 상태가 되면 들어온 순서대로 적용하며, 그때의 실제 위치에 맞는 규칙을 사용합니다. 지속 효과의 OBS 타이머도 게임과 함께 멈추고 다시 시작합니다.

방송 공지에는 다음 내용을 포함하는 것이 좋습니다.

> 1,000원 이상 후원은 Cult of the Lamb에 무작위 이벤트를 발생시킵니다. 도움뿐 아니라 신앙·포만도·체력·이동속도·공격력에 불리한 효과도 포함됩니다. 로딩이나 대화 중 들어온 이벤트는 게임 진행이 가능해진 뒤 순서대로 적용됩니다.

현재 rc35는 개발 후원을 통한 게임 적용과 표시를 검증한 배포 후보입니다. 실제 치지직 후원 수신은 수익 창출 승인 후 추가 검증이 필요합니다.

## 10. 방송 시작 전 체크리스트

- [ ] 최신 Setup EXE로 설치 또는 업데이트했다.
- [ ] Companion 창에 `v1.0.0-rc35`와 `RELEASE / CHZZK LIVE`가 표시된다.
- [ ] 방송용 치지직 계정으로 로그인했다.
- [ ] Cult of the Lamb 저장 파일을 불러왔다.
- [ ] `status`에서 `GAME=True`, `SYNC=READY`를 확인했다.
- [ ] OBS 브라우저 소스가 전체 캔버스 크기다.
- [ ] `status`에서 `OVERLAY=ready`, `OVERLAY_DOC_CURRENT=True`를 확인했다.
- [ ] `viewer open`으로 시청자 페이지가 열리고 외형을 저장할 수 있다.
- [ ] 시청자 링크와 `!신도` 명령을 공지했다.
- [ ] 후원에는 도움과 방해 효과가 모두 있다는 점을 공지했다.
- [ ] Companion 창을 방송 중 계속 켜 두었다.

## 11. 업데이트와 재설치

1. Cult of the Lamb과 Companion을 종료합니다.
2. 새 릴리스의 Setup EXE를 실행합니다.
3. 같은 게임 경로에 다시 설치합니다.
4. Companion을 실행하고 제목의 버전을 확인합니다.
5. OBS에서 오버레이 브라우저 소스를 새로고침합니다.
6. `overlay`와 `status`로 문서 버전과 연결 상태를 확인합니다.

재설치는 `%LOCALAPPDATA%\ChzzkOfTheLamb`의 사용자 설정과 시청자 매핑·외형 데이터를 삭제하지 않습니다.

## 12. 문제 해결과 지원 파일

### 설치가 실패할 때

- 게임과 Companion을 종료한 뒤 다시 시도합니다.
- 게임 경로에 `Cult Of The Lamb.exe`가 있는지 확인합니다.
- 인터넷 연결과 보안 프로그램의 차단 기록을 확인합니다.
- `%LOCALAPPDATA%\ChzzkOfTheLamb\installer.log`를 확인합니다.

### 게임과 연결되지 않을 때

- 게임에서 저장 파일을 불러와 플레이 화면까지 들어갑니다.
- Companion을 종료했다가 다시 실행합니다.
- 설치기를 다시 실행해 BepInEx, COTL_API와 Mod를 복구합니다.
- `Cult of the Lamb\BepInEx\LogOutput.log`를 확인합니다.

### 시청자 페이지에 외형이 없을 때

- 올바른 저장 파일을 불러왔는지 확인합니다.
- Companion에서 `refresh-forms`를 입력합니다.
- `status`의 `CATALOG` 값이 1 이상인지 확인합니다.
- `forms` 명령으로 허용 상태를 확인합니다.

### 진단 ZIP 만들기

Companion에서 `support`를 입력하면 바탕화면에 진단 ZIP이 생성됩니다. 자동으로 전송되지 않으므로 사용자가 내용을 확인한 뒤 개발자에게 직접 전달해야 합니다. 마지막 ZIP을 탐색기에서 찾으려면 `support open`을 입력합니다.

진단 ZIP은 OAuth 토큰, 설정 파일, 시청자 매핑·외형 내용과 게임 세이브를 포함하지 않도록 구성되어 있습니다. 그래도 외부에 공개 게시하기보다는 신뢰할 수 있는 지원 창구로 전달하는 것을 권장합니다.

### 로그 위치

```text
Companion: %LOCALAPPDATA%\ChzzkOfTheLamb\companion-rc35.log
설치기:    %LOCALAPPDATA%\ChzzkOfTheLamb\installer.log
게임 Mod:  Cult of the Lamb\BepInEx\LogOutput.log
```

## 13. 정상 종료

게임을 종료한 뒤 Companion 창에 `exit`를 입력하면 정상적으로 종료됩니다. 콘솔 창의 닫기 버튼으로 종료해도 되지만, 가능하면 `exit` 명령을 사용하세요.
