# LambLink 시청자 참여 안내

이 문서는 **LambLink v1.0.0 정식 운영 환경**에서 시청자에게 공유하는 복사용 안내문입니다. `[시청자 페이지 주소]`는 스트리머가 LambLink Companion에서 `viewer copy`를 입력해 복사한 실제 주소로 바꿔 주세요.

## 카페·디스코드·방송 설명용

> 🐑 **Cult of the Lamb 방송 속 신도로 참여해 보세요!**
>
> LambLink를 통해 시청자가 방송 속 신도가 될 수 있습니다. 시청자는 별도 프로그램을 설치할 필요가 없습니다.
>
> 🎨 **1. 내 신도 외형 저장하기**  
> 아래 시청자 페이지를 열고 치지직 계정으로 로그인해 주세요. 원하는 **형상·색상·종류**를 선택한 뒤 `이 외형으로 저장`을 누르면 준비가 끝납니다.  
> **외형 설정:** [시청자 페이지 주소]
>
> 🎟️ **2. 신도 추첨 참여하기**  
> 방송에서 새 신도 모집이 시작되면 치지직 채팅에 `!신도`를 입력해 주세요. 한 번의 추첨에는 한 계정당 한 번만 참여할 수 있습니다.
>
> ✨ **3. 당첨되면**  
> 저장한 외형과 치지직 닉네임이 게임 속 새 신도에게 적용됩니다. 시청자 신도의 이름 옆에는 초록색 `Chzzk` 표시가 붙습니다.
>
> 📖 **4. 내 신도 기록 확인하기**  
> 시청자 페이지의 `신도 히스토리 보기`에서 생성·사망·부활 기록, 누적 생존 기간과 이전 세대 외형을 확인할 수 있습니다. 이전 외형은 현재 설정으로 다시 불러올 수도 있습니다.
>
> ⚠️ **참여 전 확인해 주세요**
>
> - 현재 세대의 신도가 살아 있는 동안에는 같은 계정으로 새 신도 추첨에 다시 참여할 수 없습니다.
> - 현재 세대의 사망이 게임에서 확인되면 다음 세대 참여가 다시 열립니다. 부활하면 현재 세대가 계속 유지됩니다.
> - 외형을 저장하지 않았거나 선택한 외형을 현재 게임에서 사용할 수 없으면 안전한 기본 외형이 적용될 수 있습니다.
> - 시청자 페이지 주소는 방송 채널별 전용 링크입니다. 주소의 `?streamer=...` 부분을 삭제하거나 다른 방송의 링크와 섞지 마세요.

## 채팅 고정·반복 공지용

> 🐑 신도 참여: `[시청자 페이지 주소]`에서 치지직 로그인 후 외형을 저장하고, 모집이 시작되면 채팅에 `!신도`를 입력해 주세요! 별도 설치는 필요 없습니다.

## 추첨 시작 직전 안내용

> 🎟️ 새 신도 모집이 시작됩니다! 참여할 시청자는 채팅에 `!신도`를 입력해 주세요. 저장한 외형이 있으면 당첨 시 자동으로 적용됩니다.

## 링크가 열리지 않을 때

- 스트리머에게 최신 시청자 페이지 주소를 다시 받아 주세요.
- 주소 끝의 `?streamer=...` 값이 잘리지 않았는지 확인해 주세요.
- 치지직 로그인 창이 뜨면 방송을 시청하는 자신의 치지직 계정으로 로그인해 주세요.
- 외형 목록이 아직 없다는 메시지가 나오면 스트리머가 게임 저장 파일과 LambLink Companion을 연결할 때까지 잠시 기다려 주세요.
