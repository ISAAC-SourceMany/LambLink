# 개발 이력 보존 안내

이 디렉터리는 ChatGPT 웹 대화에서 진행된 개발 단계와 Git 이력 복원 과정에서 확보한 문서를 보존합니다. 여기 있는 내용은 작성 당시의 코드와 환경을 설명하며 현재 사용법을 뜻하지 않습니다.

## 구성

- 루트의 `devbridge*.md`, `rc*.md`, `font-fix-*.md`: 태그와 커밋별 변경 요약
- [초기 개발 이력 원문](DEVELOPMENT_HISTORY.md): devbridge10a 시점의 상세 문서
- `technical/`: 단계별 설계, 수정, 회귀 분석과 테스트 기록
- `releases/`: 이전 RC 배포 안내와 검증 기록
- `planning/`: 완료되었거나 더 이상 현재 계획이 아닌 당시 작업 계획

## 원본성

역사 문서 본문과 `SOURCE-MANIFEST.sha256`의 경로는 RC35 소스가 처음 복원됐을 당시 구조를 반영할 수 있습니다. 이후 문서 정리로 실제 파일 위치가 달라져도, 당시 변경 내역을 나타내는 경로 표기는 고치지 않습니다. Git rename 추적과 태그를 통해 원본 내용을 확인할 수 있습니다.

현재 문서는 상위 [문서 안내](../README.md)에서 확인합니다.
