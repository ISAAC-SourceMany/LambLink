# LambLink 1.0.0 — 첫 정식 공개 버전

치지직 채팅과 후원을 Cult of the Lamb에 연결하는 첫 정식 버전입니다. **새로 설치하거나 업데이트하는 경우 최신 1.0.2를 권장합니다.**

## 주요 변경사항

- 제품명과 실행 파일·설치 경로를 ChzzkOfTheLamb에서 LambLink로 통일했습니다.
- 기존 사용자 데이터를 새 경로에 없는 파일만 복사하여 이전하고, 기존 BepInEx 플러그인 식별자는 호환성을 위해 유지했습니다.
- 운영과 스테이징의 Companion·로그인·데이터·시청자 웹을 분리했습니다.
- 시청자 웹에 188개 신도 형상 미리보기, 형상별 종류와 신도 히스토리를 제공했습니다.
- 형상 선택 로딩과 래플 종료 후 신도 정보 적용 시 성능을 개선했습니다.
- 게임 속 시청자 신도 이름 옆 초록색 Chzzk 표시와 클라우드 신도 상태 복구를 지원했습니다.

## 설치와 검증

첨부된 `LambLink-Setup-1.0.0.exe`를 실행하고 게임 폴더를 선택한 뒤 Companion에서 치지직 로그인을 진행합니다. Windows x64, 파일 버전은 **1.0.0.40**입니다. 첨부된 `SHA256SUMS.txt`로 파일 해시를 확인할 수 있습니다.

이후 실사용에서 확인된 후원 수신과 오버레이 연결 문제는 1.0.1에서 개선했습니다. OBS 설정 안내는 1.0.2에서 정리했습니다. 이 릴리스는 이전 버전 기록으로 유지합니다.
