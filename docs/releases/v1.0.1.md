# LambLink 1.0.1 — 후원 처리와 오버레이 복구 개선

후원 알림을 받았지만 금액 해석에 실패하던 문제에 대응하고, 오버레이 없이도 처리 결과를 확인할 수 있도록 개선했습니다. **설치 권장은 안내를 정리한 최신 1.0.2입니다.**

## 후원 수신·결과 확인

- 치지직 후원 금액을 숫자와 문자열 형식 모두에서 처리합니다. 잘못된 자료형·소수·범위 초과는 명확한 사유로 거부합니다.
- CHAT·VIDEO 후원을 처리하며, 실패한 입력 다음의 정상 후원은 계속 처리합니다.
- 수신부터 게임 적용·카드 표시까지 같은 요청 ID로 추적할 수 있습니다.
- `donation status`로 수신·오류·적용·대기 현황을, `donation recent`로 최근 20건의 결과를 확인할 수 있습니다. 시각은 UTC입니다.

## 저장·중복 적용 방지

- 저장에 성공한 경우에만 전달 대기열을 변경하며, 손상 파일은 원본을 보존하고 처리를 차단합니다.
- 재시작·재전송과 적용 결과 저장 실패 시 중복 적용 방지를 강화했습니다.
- 적용 도중 종료되거나 확인 기록이 부족한 요청은 불확실 상태로 남기고 자동 재실행하지 않습니다.
- 게임 효과 종류·금액 구간·사용자 규칙은 유지했습니다.

## 오버레이 복구

- 로컬 HTML이 Companion 연결을 재시도하여 실행 순서와 Companion 재시작에 대응합니다.
- 연결이 없는 동안 후원 카드를 기다렸다가 재연결 후 안내합니다. 대기는 최대 100건·30분이며 게임 효과를 다시 실행하지 않습니다.
- 개별 카드의 페이지 표시 응답을 기록합니다. 이 응답이 실제 OBS 송출까지 증명하는 것은 아닙니다.

## 설치·업데이트

첨부된 `LambLink-Setup-1.0.1.exe`로 Companion과 Mod를 함께 업데이트하세요. Windows x64, 파일 버전 **1.0.1.41**이며 설치 중 인터넷 연결이 필요합니다. `SHA256SUMS.txt`는 첨부 설치기의 검증용입니다.

OBS 브라우저 소스에서 **로컬 파일**을 켜고 Companion의 `overlay file` 명령에 표시되는 `LambLink-Overlay.html`을 선택하세요. 기존 HTTP 소스는 한 번 전환해야 합니다. 이 버전은 호환 HTTP 주소도 함께 출력하며, 그 혼동은 1.0.2에서 해소했습니다.

Mod 적용 기록은 v2로 저장하며 기존 v1 원본을 `.v1.bak`로 보존합니다. 백업을 단순 복원하면 이후 적용 기록을 잃으므로 구버전으로 자동 복원하지 마세요.

## 확인한 범위

후원 자동 테스트 14개 그룹, 브라우저 복구 테스트, Release 빌드 및 CDN 다운로드 해시 검증을 통과했습니다. 실제 치지직 후원·실게임·OBS의 전체 통합 검증은 미완료입니다. 과거 장애의 원문 패킷은 없어 당시 세 건의 정확한 입력 형식을 확정하지는 못했습니다.
