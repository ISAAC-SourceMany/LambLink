# LambLink 1.0.2 — OBS 설정 안내를 로컬 파일 하나로 통일

OBS 설정에서 로컬 파일과 HTTP 주소 중 무엇을 선택할지 헷갈리지 않도록 안내를 정리했습니다. **신규 설치와 업데이트는 이 버전을 사용하세요.** 1.0.1의 후원 처리·저장·복구 개선도 모두 포함합니다.

## 1.0.1 대비 변경사항

- Companion 시작 로그에서 호환 HTTP 주소 안내를 제거했습니다.
- `overlay` 명령은 OBS에서 선택할 로컬 HTML 파일 하나만 안내합니다.
- 도움말의 오버레이 명령을 `overlay` 중심으로 정리했습니다.
- 오래된 오버레이 문서에 대한 안내도 로컬 파일 경로를 확인하도록 통일했습니다.
- 내부 HTTP 연결 방식과 후원·게임 규칙은 유지했습니다.

## 설치·OBS 설정

1. 첨부된 **`LambLink-Setup-1.0.2.exe`**를 다운로드해 실행합니다.
2. 게임 폴더를 확인하고 Companion과 Mod를 함께 업데이트합니다. 설치 중 인터넷 연결이 필요합니다.
3. Companion에서 `overlay`를 입력합니다.
4. OBS 브라우저 소스에서 **로컬 파일**을 켜고 안내된 `LambLink-Overlay.html`을 선택합니다. HTTP 주소는 따로 입력하지 않습니다.

이미 로컬 파일을 지정했다면 그 설정을 계속 사용하면 됩니다. Windows x64, 파일 버전은 **1.0.2.42**입니다. 첨부된 `SHA256SUMS.txt`로 설치 파일을 검증할 수 있습니다.

## 검증과 제한

Release 빌드와 구성 파일 검증을 통과했고, 배포용 프로그램에 HTTP 선택 안내가 남지 않은 것을 확인했습니다. 게시된 설치기·Mod·Companion·한글 폰트를 CDN에서 내려받아 해시 일치를 확인했습니다.

이번 버전은 안내 문구와 버전 정보 변경입니다. 1.0.1에서 확인한 자동 테스트 결과를 기반으로 하며, 실제 치지직·게임·OBS의 전체 통합 검증은 여전히 미완료입니다. 적용 기록 v2의 구버전 복원 제한도 동일합니다.
