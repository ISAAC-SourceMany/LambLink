# LambLink 1.0.3 — OBS 오버레이 검은 배경 수정

로컬 HTML 오버레이가 Companion에 연결되면 배경 전체가 검게 변해 게임을 가리던 문제를 수정했습니다. 부모 iframe과 내부 오버레이의 색상 모드를 맞춰 카드 밖 영역의 투명도를 유지합니다.

## 설치 후 적용

1. 첨부된 `LambLink-Setup-1.0.3.exe`를 실행해 업데이트합니다.
2. Companion을 한 번 실행합니다. 기존 `LambLink-Overlay.html`이 수정본으로 갱신됩니다.
3. OBS 오버레이 브라우저 소스 속성에서 **현재 페이지 새로고침**을 누릅니다.

기존 로컬 파일 경로와 방송 캔버스 크기는 그대로 사용합니다. 사용자 지정 CSS나 크로마키 설정은 필요하지 않습니다. Windows x64, 설치기/Companion 파일 버전은 `1.0.3.43`입니다.

## 검증

- 수정 전 Chromium에서 카드 밖 배경 `RGBA(18,18,18,255)`를 재현했습니다.
- 수정 후 서버 연결 전·연결 후·종료 후·후원 카드 표시 중 배경 알파값 0을 확인했습니다.
- 밝은/어두운 OS 테마, 서버 재시작, 응답 실패/지연, 브라우저 재열기, 후원 표시 대기 회귀 테스트를 통과했습니다.
- 실제 OBS 장면에서의 최종 수동 확인은 아직 하지 않았습니다.

이 릴리스는 오버레이 합성 문제 수정입니다. 기존 1.0.2의 후원·신도·저장 기능을 포함합니다.
