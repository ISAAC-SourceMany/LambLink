# LambLink 1.0.4 — 후원 효과 이름 개선

후원 이벤트 49종의 이름을 실제 효과와 수치가 보이는 표현으로 변경했습니다.

- 작은 신앙의 축복 → 신앙 5 증가
- 열정 충전 → 열정 최대치의 20% 회복
- 둔화의 장난 → 이동속도 15% 감소
- 전투의 축복 → 공격력 20% 증가
- 광전사의 축복 → 이동속도·공격력 25% 증가
- 적을 향한 일격 → 적 전체에 고정 피해 0.5

적 피해는 퍼센트가 아닌 고정 수치입니다. 게임에서 지역을 재판정하는 경로의 이름도 변경했습니다.
효과량·지속시간·연속 적용 방식은 변경하지 않았으며, 1.0.3의 OBS 투명 배경 수정도 포함됩니다.

## 설치

첨부된 `LambLink-Setup-1.0.4.exe`를 다운로드하세요.
게임 저장·종료 → 설치 → Companion과 게임 재실행 → OBS 소스 새로고침 순서로 업데이트합니다.
설치기 및 Companion Windows 파일 버전은 `1.0.4.44`입니다.

## 검증 범위

49종 명칭 검사를 포함한 후원 회귀 테스트 15개 그룹이 통과했습니다.
실제 게임·치지직·OBS 통합 수동 검증은 이번 변경에서 수행하지 않았습니다.
