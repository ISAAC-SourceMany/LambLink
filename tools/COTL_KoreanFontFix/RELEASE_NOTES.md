# Release Notes — 4.3.0

- Diagnostic atlas tracing removed.
- KoreanRuntimeFont remains Static.
- Runtime glyph generation remains disabled.
- Primary TMP font replacement remains disabled.
- KoreanRuntimeFont is used only through global/per-font fallback.
- NFC normalization and TMP_InputField IME support retained.
- Project references include UnityEngine, TextRenderingModule, UnityEngine.UI and the modular Unity assemblies required by the current Cult of the Lamb build.
- Added `package-release.ps1` for streamer-ready ZIP packaging.
